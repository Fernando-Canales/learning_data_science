# Data Science Transition 🚀

## Objetivo
Repositorio estructurado para documentar la transición de Astrofísica a roles de Data Science y Software Engineering (BairesDev, Alignerr).

## Metodología de Estudio
- **Inspección de Textos:** Método Socratica.
- **Síntesis de Conceptos:** Técnica Feynman (apoyada con libreta física tipo actas).
- **Mentoría:** Evaluaciones algorítmicas Socráticas usando modelos locales (Qwen3/DeepSeek) vía Ollama.

## Estructura del Repositorio
* `📚 References/` - Bibliografía (Rybicki, Sivia, Kolmogorov, etc.) y notas.
* `💻 Projects/` - Código de algoritmos (Project Euler), SQL y ML.
* `📝 StudyPlans/` - Resúmenes Feynman y preparación técnica.
* `🧰 Tools/` - (Ignorado en Git) Entornos aislados de Python.
* `📁 Data/` - (Ignorado en Git) Datasets locales para pruebas.
